# Engineering guidance — Valoria Institute public site

Apply the project engineering standards in `docs/engineering/ASD-STE100.md` to technical documentation, procedures, test evidence, pull requests, incidents, and user-facing technical instructions.

Preserve approved Valoria terminology, brand language, PRIME definitions, VALU assessment boundaries, marketplace identity model, scoring contracts, and legal meaning. Do not simplify text in a way that changes product rules or user expectations.

For all changes:
- Verify the relevant existing behavior before modifying it.
- Keep public and private profile data separate.
- Do not use user-editable metadata as an authorization source.
- Do not expose Supabase service-role credentials in browser code.
- Keep assessment, scoring, and marketplace eligibility rules consistent with the authoritative platform contracts.
- Record test evidence and verify user-visible behavior in the deployed environment.
- Use the engineering review checklist before release.

The ASD-STE100 policy is STE-aligned guidance. It is not a claim of formal compliance with the complete official standard.
